# news-similarity

Case Study 3: Text Similarity in News Articles.

The goal of this project is to measure how similar a set of news articles are
to each other using text-processing and similarity techniques in Python.
The pipeline loads the articles, preprocesses them, computes the Jaccard and
cosine similarity between all pairs, generates heatmaps and writes a Markdown
report.

## Usage

1. Place your news articles as `.txt` files (UTF-8) in `data/articles/`.

2. Create and activate a virtual environment:

   ```bash
   python -m venv venv
   # Windows
   venv\Scripts\activate
   # macOS / Linux
   source venv/bin/activate
   ```

3. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the project:

   ```bash
   python main.py
   ```

   > **Note:** the first run of `main.py` downloads the NLTK resources
   > (`punkt`, `punkt_tab` and `stopwords`) and requires an internet
   > connection. Later runs reuse them and work offline.

## Outputs

Running `main.py` creates the `results/` folder (if needed) with these files:

| File | Description |
| --- | --- |
| `jaccard_matrix.csv` | Pairwise Jaccard similarity between all articles (square matrix). |
| `cosine_matrix.csv` | Pairwise cosine similarity between all articles, based on term frequencies (square matrix). |
| `jaccard_heatmap.png` | Heatmap of the Jaccard similarity matrix. |
| `cosine_heatmap.png` | Heatmap of the cosine similarity matrix. |
| `pairs_ranking.csv` | Every pair of articles with its Jaccard and cosine similarity, sorted by cosine (descending). |
| `report.md` | Markdown report: dataset summary, most and least similar pairs, metric comparison, limitations and an interpretation placeholder. |
