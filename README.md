# news-similarity

Case Study 3: Text Similarity in News Articles.

The goal of this project is to measure how similar a set of news articles are
to each other using text-processing and similarity techniques in Python.
The pipeline loads the articles, preprocesses them, computes the Jaccard and
cosine similarity between all pairs, generates heatmaps and writes a Markdown
report.

## Data

The articles in `data/articles/` come from the Reuters corpus included in
NLTK. They are exported by `scripts/fetch_articles.py`, which selects 3
articles for each of three topics: `crude`, `grain` and `acq`. An article is
selected if:

- its only category is the topic,
- it has between 150 and 500 words,
- it mentions the topic at least 4 times in total, counting whole-word,
  case-insensitive occurrences of these keywords:
  - `crude`: oil, crude
  - `grain`: grain, wheat, corn
  - `acq`: acquire, acquisition, bid, takeover, stake, offer
- digits make up no more than 5% of its characters (this skips numeric
  tables).

File ids are scanned in alphabetical order and the first 3 matches per topic
are kept, so the selection is reproducible. Each article is saved as
`<topic>_01.txt`, `<topic>_02.txt` and `<topic>_03.txt`.

To regenerate them (the corpus is downloaded on first use):

```bash
python scripts/fetch_articles.py
```

The script does not overwrite existing `.txt` files in `data/articles/`
unless you pass `--force`.

During preprocessing, HTML entities are unescaped and text between angle
brackets (tickers such as `<BUD.N>`) is removed. Besides NLTK's English stop
words, these domain stop words are removed because they are newswire
boilerplate: said, says, also, would, could, year, years, reuters, mln, pct,
dlrs, billion, today, told, new.

## Usage

1. Place your news articles as `.txt` files (UTF-8) in `data/articles/`.

2. Create and activate a virtual environment:

   ```bash
   python -m venv venv
   # Windows
   venv\Scripts\activate
   # macOS / Linux
   source venv/bin/activate
   ```

3. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the project:

   ```bash
   python main.py
   ```

   > **Note:** the first run of `main.py` downloads the NLTK resources
   > (`punkt`, `punkt_tab` and `stopwords`) and requires an internet
   > connection. Later runs reuse them and work offline.

## Outputs

Running `main.py` creates the `results/` folder (if needed) with these files:

| File | Description |
| --- | --- |
| `jaccard_matrix.csv` | Pairwise Jaccard similarity between all articles (square matrix). |
| `cosine_matrix.csv` | Pairwise cosine similarity between all articles, based on term frequencies (square matrix). |
| `jaccard_heatmap.png` | Heatmap of the Jaccard similarity matrix. |
| `cosine_heatmap.png` | Heatmap of the cosine similarity matrix. |
| `pairs_ranking.csv` | Every pair of articles with its Jaccard and cosine similarity, sorted by cosine (descending). |
| `report.md` | Markdown report: dataset summary, most and least similar pairs, metric comparison, limitations and an interpretation placeholder. |
